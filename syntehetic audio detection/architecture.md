# PRISM Architecture & Mechanics Specification
*Probabilistic Recognition of Inauthentic Spectral Markers (PRISM)*

This document provides an in-depth, step-by-step technical explanation of how each component in the PRISM system works, and how the heuristic Tier A pipeline is mathematically connected to the supervised Tier B classifier.

---

## 🔗 The Core Relationship: Tier A & Tier B

To understand PRISM, think of it as a biological sensory system:

```
┌──────────────────────────────────────────────┐
│                  RAW AUDIO                   │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│            TIER A: SENSORY ORGANS            │
│  - Extracts custom DSP features from audio    │
│  - Measures specific physical artifacts      │
│  - Generates raw, uncalibrated scores        │
└──────────────────────┬───────────────────────┘
                       │ 
                       ▼ (14-Dimensional Feature Vector)
┌──────────────────────────────────────────────┐
│                TIER B: BRAIN                 │
│  - Learns the PATTERN of Tier A scores       │
│  - Finds non-linear decision boundaries      │
│  - Outputs calibrated probabilities (0 to 1)  │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│            REAL / SYNTHETIC DECISION         │
└──────────────────────────────────────────────┘
```

*   **Tier A is the Feature Extractor**: Tier A analyzes the raw binary waveform and extracts specialized mathematical measurements (vocoder artifacts, GAN checkerboards, diffusion decay, stats anomalies).
*   **Tier B is the Decision Maker**: Tier B **does not look at raw audio**. It takes the 14 numbers generated by Tier A, calculates contrasts between them, and uses a Support Vector Machine (SVM) to make the final determination.
*   **Why this relationship works**: By using Tier A as a DSP feature extractor, we reduce millions of raw audio samples into just 14 highly descriptive numbers. This allows Tier B to train instantly (in seconds) and generalize perfectly on very small datasets (500–1000 files) without overfitting.

## 🛠️ Component-by-Component Mechanics

---

### 1. Stage 1: Preprocessor (`preprocessor.py`)
Raw audio files come in all shapes and sizes (different codecs, stereo formats, sample rates). The preprocessor standardizes them.

1.  **Resampling (Decimation)**: Resamples the signal to **$22,050\text{ Hz}$** using Kaiser window interpolation. This is the optimal sample rate to capture up to the Nyquist limit of $11,025\text{ Hz}$, which contains the high-frequency boundaries where vocoders and diffusion models fail.
2.  **Downmixing**: Converts multi-channel stereo audio to mono by averaging channels: $x_{\text{mono}}[n] = \frac{x_L[n] + x_R[n]}{2}$.
3.  **DC Offset Filtering**: Applies a 2nd-order Butterworth High-Pass Filter with a cutoff at $20\text{ Hz}$. Sub-audible frequencies ($<20\text{ Hz}$) introduce DC bias offsets which skew spectral centroid math.
4.  **Peak Normalization**: Scales the signal so that the absolute maximum amplitude is exactly $1.0$: $x_{\text{scaled}}[n] = \frac{x[n]}{\max(|x|)}$.

---

### 2. Stage 2: Domain Classifier (`domain.py`)
Synthesis artifacts look different depending on whether the audio is voice, instruments, or ambient noise. The domain classifier identifies the class.

*   **Zero Crossing Rate (ZCR)**:
    $$ZCR = \frac{1}{N-1} \sum_{n=1}^{N-1} \mathbb{I}(x[n] \cdot x[n-1] < 0)$$
    *Speech has rapid sign changes due to fricatives (like "s", "f"). Environmental noise is lower frequency.*
*   **Spectral Centroid**: The center of gravity of the spectrum:
    $$f_c = \frac{\sum_{k} f[k] \cdot |X[k]|}{\sum_{k} |X[k]|}$$
    *Speech peaks heavily in lower-middle bands ($1200\text{ Hz} - 2200\text{ Hz}$). Environmental noise is wide or concentrated elsewhere.*
*   **Spectral Rolloff**: The frequency threshold $f_r$ below which 85% of spectral power sits:
    $$\sum_{k=0}^{f_r} |X[k]|^2 = 0.85 \sum_{k=0}^{N/2} |X[k]|^2$$
    *Music contains rich high-frequency harmonics, causing a high rolloff ($>6000\text{ Hz}$). Speech rolls off early ($<3500\text{ Hz}$).*
*   **MFCC[1] Variance**: Variance of the first MFCC coefficient over time windows.
    *Music displays high modulation variance over time. Noise and speech are more static.*

**Additive Voting System (Calibrated for Wideband Speech)**:
Instead of forcing a single feature to dictate the domain, each feature contributes a raw score. ZCR, centroid, and rolloff votes are combined. If any single vote is exceptionally high (e.g. high ZCR) or if they agree, `speech_raw` is boosted. This routes the audio to the correct domain even if part of the file is silent.

---

### 3. Stage 3: Tier A Specialized Heuristic Detectors (`detectors.py`)

#### A. Vocoder Detector (envelope valley smoothness)
*   **Intuition**: Human speech contains clean, natural "valleys" between vowel formants. Neural vocoders (like HiFiGAN) and traditional vocoders (LPC) struggle to reconstruct phase alignment in these low-energy valleys, leaving them unnaturally smooth or mathematically uniform.
*   **How it works**:
    1. Computes the Log-Mel Spectrogram.
    2. Isolates the spectral envelope valleys (local minima).
    3. Calculates the first-order difference (derivative) of the valley envelope across frequency bands.
    4. Computes the temporal variance of these derivatives. High variance indicates natural transitions; low, flat variance indicates artificial vocoder reconstruction.

#### B. GAN Detector (2D spatial FFT peak grids)
*   **Intuition**: GAN generators build audio waveforms using **transposed convolutions** (up-sampling). When these filter kernels overlap, they create a periodic "checkerboard" pattern of grid lines in the spectrogram.
*   **How it works**:
    1. Extracts the magnitude spectrogram image.
    2. Performs a 2D Fast Fourier Transform (FFT) on the spectrogram image.
    3. This treats the spectrogram as a 2D image and detects repeating patterns.
    4. If there is a repeating grid pattern (transposed convolution artifact), the 2D FFT will display sharp, periodic spike peaks at specific spatial frequencies. The detector measures the strength of these peaks.

#### C. Diffusion Detector (high-frequency decay curve regression)
*   **Intuition**: Diffusion models start with pure white noise and iteratively denoise it. They struggle to generate high-frequency ranges ($>8\text{ kHz}$) cleanly, either rolling them off too abruptly or leaving high-frequency residual noise.
*   **How it works**:
    1. Computes the average power spectrum of the audio.
    2. Takes the high-frequency band ($8,000\text{ Hz}$ to $11,025\text{ Hz}$).
    3. Fits a linear regression line to the log-magnitude energy decay: $y = mx + c$.
    4. Calculates the Mean Squared Error (MSE) and slope deviation from a natural human decay template. Large deviations indicate diffusion artifacts.

#### D. Unsupervised Anomaly Detector (`artifact_stats_detector.py`)
*   **Intuition**: Even if an AI generator manages to avoid vocoder, GAN, and diffusion artifacts, it might still create an audio distribution that feels "unnatural" overall.
*   **How it works**:
    1. Extracts three global statistical features: Spectral Flux (rate of spectral change), Spectral Flatness (noise-like vs tonal-like), and Temporal Energy Entropy.
    2. Passes these to an **Isolation Forest** model trained only on authentic, real audio.
    3. If the forest isolates the sample quickly (short path length), it means the statistical profile is anomalous compared to natural human recordings.

---

### 4. Stage 4: Aggregator (`aggregator.py`)
The aggregator combines the individual detectors into a single Tier A score.

If we hard-routed speech to only use the vocoder detector, a slight domain classification error would break the system. Instead, the aggregator uses **soft probability routing**:

$$\text{artifact\_score} = \sum_{d \in \text{domains}} \text{probs}[d] \times \left( \sum_{s \in \text{detectors}} \text{weight}[d][s] \times \text{score}[s] \right)$$

*Example*: If a file is classified as $90\%$ speech and $10\%$ environmental:
*   The speech weights ($40\%$ vocoder, $30\%$ GAN, $20\%$ diffusion, $10\%$ anomaly) get a $0.90$ multiplier.
*   The environmental weights ($10\%$ vocoder, $30\%$ GAN, $20\%$ diffusion, $40\%$ anomaly) get a $0.10$ multiplier.
*   The final score blends both profiles proportionally, maintaining robustness.

---

### 5. Stage 5: Tier B Feature Matrix & SVM Engine (`train_tier_b.py`)
Tier B is the machine learning supervisor. It translates Tier A's uncalibrated heuristics into a single, clean probability score.

#### Feature Matrix Design (14 Dimensions)
Rather than feeding raw scores alone, Tier B constructs a feature vector that highlights **contrasts**:

1.  **Raw Scores (1–5)**: `vocoder_score`, `gan_score`, `diffusion_score`, `artifact_score`, `anomaly_score`.
2.  **Pairwise Differences (6–7)**: `vocoder - GAN`, `GAN - diffusion`. This allows the classifier to see if one artifact dominates over another, representing generator footprints (e.g. WaveFake is heavy on vocoder artifacts, whereas GAN audio is heavy on GAN artifacts).
3.  **Contrasts against Anomaly (9–11)**: `vocoder - anomaly`, `GAN - anomaly`, `diffusion - anomaly`. Checks if the physical detector matches the statistical anomaly signature.
4.  **Max Peak (8)**: $\max(\text{vocoder}, \text{GAN}, \text{diffusion})$. Captures cases where only one detector is triggered but with extreme confidence.
5.  **One-Hot Domain Context (12–14)**: `is_speech`, `is_music`, `is_environmental`. Injects categorical context so the model applies different geometric thresholds based on domain.

#### Support Vector Machine (SVM) Classification
The feature vector $\mathbf{x} \in \mathbb{R}^{14}$ is fed into a Support Vector Classifier (SVC) utilizing a **Radial Basis Function (RBF)** kernel:

$$K(\mathbf{x}, \mathbf{x}') = \exp(-\gamma \|\mathbf{x} - \mathbf{x}'\|^2)$$

*   **RBF Kernel**: Projects the 14 features into an infinite-dimensional Hilbert space. This allows the model to draw complex, curved, non-linear decision boundaries around the clusters of real and synthetic audio.
*   **Platt Scaling (Calibration)**: Standard SVMs only output distances to the decision hyperplane. Platt scaling fits a logistic regression model over the SVM outputs:
    $$P(y=1 | \mathbf{x}) = \frac{1}{1 + \exp(A \cdot f(\mathbf{x}) + B)}$$
    This converts the output into a calibrated probability value (`tier_b_prob`) between $0.0$ and $1.0$.
*   **Threshold (0.50)**: Since `tier_b_prob` is a calibrated probability, the exact center $0.50$ serves as the decision boundary.
